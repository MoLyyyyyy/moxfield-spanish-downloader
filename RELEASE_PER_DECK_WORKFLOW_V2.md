# Per-deck workflow v2

Esta versión rehace el soporte multimazo para mantener cada mazo aislado hasta
la exportación final.

Cambios principales:
- Configuración independiente de Scryfall/MPCFill por mazo.
- Idioma, respaldo, edición y calidad independientes.
- Sideboard y maybeboard independientes.
- Análisis secuencial mazo por mazo.
- Galería, edición manual y acciones masivas limitadas al mazo activo.
- Navegación y estado de revisión independientes.
- Concatenación únicamente durante la generación del PDF.
