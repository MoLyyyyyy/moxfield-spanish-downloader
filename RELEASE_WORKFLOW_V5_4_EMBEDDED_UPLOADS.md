# Workflow v5.4 embedded uploads

- Los proyectos JSON ahora incluyen las imágenes subidas manualmente.
- Al restaurar un proyecto, dichas imágenes se reconstruyen automáticamente en la caché local.
- La huella de integridad del proyecto usa identificadores estables para las imágenes subidas, sin depender de rutas locales.
- El mensaje de carga del proyecto indica cuántas imágenes subidas se han restaurado.
