# Dual card fix v3

Correcciones de versiones para cartas dobles:

- Los separadores `A / B` y `A // B` son equivalentes.
- Scryfall valida siempre el nombre completo de la carta.
- La selección manual de Scryfall conserva todas las caras físicas.
- El selector muestra las dos caras antes de elegir una impresión.
- MPCFill busca primero el nombre completo y después la cara frontal.
- Las búsquedas exactas con set code no aceptan otra edición aunque falte
  el número de coleccionista.
- Las cachés de alternativas incluyen nombre completo, set y número.
