# Verificación de Proxy Maker Studio

Fecha: 2026-08-28. Rama: `studio-redesign`. Base: `cf07e68`.

## Cambios

- Tema carbón y verde suave en web y lanzador Windows.
- Navegación Importar / Revisar / PDF con bloqueo si cambia el borrador.
- Mazos y proyectos en el lateral; galería visible junto al editor.
- Controles compactos, detalles secundarios agrupados y diseño apilado en
  ventanas estrechas. Se mantienen fuentes, filtros, recorte y reparto.
- Vista previa reducida del PDF generado, con anversos/reversos y partes.
  Solo se conserva el último bitmap, con recursos nativos cerrados y acceso
  a PDFium serializado. Cambiar selecciones invalida salida y vista previa.
- Se conservan aviso de huecos y validaciones de exportación.

No se cambian los motores de resolución, las dimensiones del PDF, la política
de alta resolución, los códigos de traseras ni el formato de proyectos.
